# ThermoIntel — SIH26162 Alignment

ThermoIntel implements the requested geospatial thermal-monitoring workflow through a multi-source evidence pipeline:

1. **NASA FIRMS** — near-real-time VIIRS/MODIS active-fire and thermal-anomaly detections.
2. **Spatio-temporal event clustering** — converts individual detections into persistent thermal events.
3. **OSM industrial infrastructure** — nearest facilities, facility type, industrial proximity and density.
4. **ESA WorldCover 2021 v200** — 10 m satellite-derived land-cover sampling around each event, with OSM as a fallback when the WorldCover COG is unavailable.
5. **Satellite visualization** — NASA GIBS thermal/imagery layers and ESA WorldCover visualization.
6. **Source classification** — INDUSTRIAL FIRE, GAS FLARE / INDUSTRIAL THERMAL SOURCE, FOREST / VEGETATION FIRE, AGRICULTURAL BURNING, and OTHER THERMAL SOURCE.
7. **Risk fusion** — thermal intensity + persistence + industrial exposure + source-class evidence.
8. **GIS dashboard** — event map, classification, confidence, land-cover source, evidence, facility context and risk.

## Classification integrity

The system deliberately separates **detection** from **source classification**. FIRMS reports satellite-derived active-fire/thermal-anomaly detections; NASA notes that these detections may originate from fire, agriculture or other sources and should be interpreted with spatial resolution and confidence information. ThermoIntel therefore does not treat a FIRMS point as proof of an industrial fire.

The final label is generated by deterministic multi-source evidence fusion. Industrial labels require mapped industrial evidence; agricultural labels require cropland evidence; forest/vegetation labels require vegetation land-cover evidence; flare labels require a nearby hydrocarbon-related industrial signal. When contextual evidence is insufficient, the system returns **OTHER THERMAL SOURCE** rather than inventing a cause.

## AI/ML honesty

The included source classifier is an **explainable evidence-fusion classifier**, not a trained supervised ML model. The repository contains no verified ground-truth fire-cause training dataset, so the submission intentionally does not claim fabricated model accuracy, precision, recall or F1 values. The API stores per-class evidence scores and the evidence used for the decision.

## Data provenance

- NASA FIRMS: thermal/active-fire observations.
- ESA WorldCover 2021 v200: 10 m land-cover map derived from Sentinel-1 and Sentinel-2 data.
- OpenStreetMap/Overpass: industrial infrastructure and fallback land-use context.
- NASA GIBS: satellite visualization layers.

## Demonstration expectation

A running demonstration requires a valid NASA FIRMS MAP_KEY and internet access from Docker for FIRMS, WorldCover COG range reads, and OSM queries. Existing databases are upgraded automatically; startup re-enriches the recent seven-day event population so older OSM-only land-cover records are replaced with satellite-derived WorldCover evidence where available.
